# Guided demos

A guided demo runs one of the thirteen validated test motors inside the real application, with a
speech bubble that anchors itself to the actual control you need next and waits for you to use it.
Nothing is simulated: the settings you are walked through are the settings the milestone was
validated at, and the run at the end is a real rebuild producing a real STEP.

Start one from **Help > Guided Demos** — see *Status in this build*, at the foot of this page,
before you go looking for it. The picker generates the demo's mesh on demand — the
repository ships the generators, not the meshes — and then hands over to the walkthrough.

## The thirteen

| # | Name | What it teaches |
|---|---|---|
| M1 | Simple Tube Grain | the whole workflow at its simplest, plus the render modes |
| M2 | Domed Capsule, Straight Bore | domes, the dome-cap fit layer, and the station table |
| M3 | Six-Point Star Bore | a non-circular bore, seen with Section view |
| M4 | Finocyl — Bore-to-Fin Transition | a topology event, and A/B comparison against the input |
| M5 | Domed Finocyl, Adaptive Stations | when adaptive station placement earns its keep |
| M6 | Tapered Star (Lofted Profiles) | a cross-section that changes shape along the axis |
| M7 | Central Bore + Six Satellite Perforations | multiple loops per station, and chains that die |
| M8 | Mid-Burn Slotted Grain | filleted slot ends, and the deviation heatmap |
| M9 | Noisy Scan Input — Reading a "Failed" Check | a run that fails a check on purpose, and why |
| M10 | Tiny, Tilted, and in Inches — Frame Auto-Detection | axis auto-detection and unit normalisation |
| M11 | Three-Segment BATES (Multi-Solid Output) | one STL becoming three solids |
| M12 | Near-Burnout — Slots Breaking Through the Dome | the hardest topology the engine handles |
| M13 | Dirty Real-World Capstone (5M Triangles, Inches) | five million triangles, in inches, end to end |

## Two of them are slow

**M9** and **M13** need `scikit-image` installed, because their meshes are generated by marching
cubes. M9's mesh is around 44 MB and takes about a minute to generate. **M13's is around 253 MB,
takes several minutes to generate, and its Analyze step alone can run about nineteen minutes** —
start that one before lunch. The picker warns you before it begins either.

## The one to do second

**M9** is the demo worth the time even if you skip the rest. It runs a milestone at its own
official settings and ends with a **failed** verification check, on purpose, because learning to
read a failure is more useful than watching thirteen successes. See the Verification page for the
written version of the same lesson.
