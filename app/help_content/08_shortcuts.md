# Keyboard shortcuts

Every shortcut in the application, in one place.

## File

| Key | Action |
|---|---|
| Ctrl+O | Open STL |
| Ctrl+E | Export viewport image |
| Ctrl+Q | Quit |

## Run

| Key | Action |
|---|---|
| F5 | Analyze |
| Ctrl+R | Run |
| Esc | Cancel the in-flight run |

## View

| Key | Action |
|---|---|
| B | Swap input to rebuilt (A/B comparison) |
| F | Fit view |
| O | Orthographic projection |
| S | Section view |
| W | Cycle render mode |
| Ctrl+1 | Render mode: Shaded |
| Ctrl+2 | Render mode: Shaded + edges |
| Ctrl+3 | Render mode: Wireframe |

## Help

| Key | Action |
|---|---|
| F1 | Quick Start Guide |

## Notes

- **Esc** does nothing when no run is in flight — the Cancel action is disabled then.
- **W** has no menu entry of its own; it cycles the three Render mode entries in order.
- The layer toggles (Input mesh, Rebuilt solid, Station rings, Dome-cap fit, Topology events,
  Axis line) and the two remaining comparison modes (Rebuilt solid: transparent, Input mesh: solid
  color) have **no shortcuts**. Use the View menu, or click the legend row in the top right of the
  viewport.
- The Deviation heatmap has no shortcut either; it is on the View menu and on the display-toggle
  overlay at the top left of the viewport.
